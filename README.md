# Maple Weapp

A lightweight UI component library for native WeChat Mini Programs.

## Features

- Native WeChat Mini Program
- TypeScript
- Lightweight
- WebView friendly
- Skyline friendly
- Easy to use

## Components

- Button
- Cell
- Icon
- Loading
- Input
- Textarea
- Switch
- Checkbox
- Radio
- Tag
- Toast
- Dialog
- Popup
- ActionSheet
- Card
- List
- Tabs
- Navbar
- Tabbar

## Development

Install dependencies:

```bash
npm install
```

Run TypeScript validation:

```bash
npm run typecheck
```

The library targets native WeChat Mini Programs. The `examples/miniprogram` directory contains the demo project.
